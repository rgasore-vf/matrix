# Constat avant lecture de la spécification dérivée

Le ZIP matrix-main.zip contient 66 fichiers sous smv_indicator uniquement. Aucun dossier Strategie/, aucune transcription ni image originale de formation, aucun historique Git ni ancien EA. README indique que ces ressources sont les sources de vérité mais elles sont absentes. Il est impossible de reconstruire indépendamment la stratégie depuis les sources primaires, de confirmer A→B et A→C, ou de vérifier les affirmations historiques de Claude. Toute règle issue de STRATEGY_SPEC sera traitée comme une assertion dérivée et non comme une preuve primaire.

L’audit poursuivra B→C, causalité temporelle, robustesse, tests, calculs de recherche et parité MT5. Les recherches externes ne pourront remplacer la formation. Aucune définition externe ne sera attribuée au formateur sans preuve.
